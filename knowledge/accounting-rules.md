# 会計ルール・自動仕訳方針

## 1. 基本
ユーザーには収入・支出の簡単入力を提供し、内部では複式簿記の仕訳を生成する。金額は日本円の整数で扱う。

## 2. 発生と決済
収益・費用の発生日と、現金の入金・支払日を分ける。
- 未入金売上：売掛金 / 売上高
- 売掛金入金：普通預金等 / 売掛金
- 未払経費：費用 / 未払金等
- 未払金支払：未払金等 / 普通預金等

## 3. 仕訳のルール
- 仕訳は最低2明細で構成する。
- 各明細は借方・貸方のどちらか一方に正の金額を持つ。
- 仕訳確定時に借方合計と貸方合計を一致させる。
- 仕訳確定後の直接編集は避け、取消・再計上で訂正する。
- 二重送信・二重計上を防ぐため冪等性を実装する。

## 4. 個人事業主特有の取引
- 事業用資金を生活費に使う場合は事業主貸等を使用する。
- 個人資金で事業経費を支払う場合は事業主借等を使用する。
- 家事按分が必要な費用は、将来、事業使用割合・按分額・根拠を記録できるようにする。

## 5. 注意事項
この文書はアプリ内部の初期ルールであり、個別取引の税務判断を保証するものではない。消費税、源泉徴収、固定資産、家事按分、棚卸、減価償却等は、機能追加時に専門家レビューと公的資料確認を行う。
