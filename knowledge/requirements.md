# 要件定義書

## 1. 目的
日本の個人事業主が、日々の収入・支出を簡単に記録し、会計状況を把握できるiPhone向け会計アプリを開発する。将来的な一般公開を想定し、複数ユーザーのデータを安全に分離する。

## 2. 対象範囲
- 対象ユーザー：日本の個人事業主
- 通貨：日本円（JPY）のみ
- 会計期間：暦年（1月1日〜12月31日）
- 申告方式：青色申告・白色申告の両方を考慮
- 入力方式：ユーザーは簡単入力を行い、アプリ内部で複式簿記の仕訳を作成する
- 初期端末：iPhone
- クライアント：Expo / React Native / TypeScript
- バックエンド候補：Supabase / PostgreSQL

## 3. MVP機能
1. ユーザー登録・ログイン
2. 事業者プロフィール・会計設定
3. 収入登録
4. 支出登録
5. 取引一覧・詳細・編集
6. 入金・支払状況の管理
7. 自動仕訳の作成・閲覧
8. 月別・年別の収支集計
9. ユーザー・事業者単位のデータアクセス制御

## 4. 将来拡張
- 領収書画像の保存・OCR
- 銀行・クレジットカード連携
- 消費税区分・税率別集計の拡張
- 青色申告決算書・収支内訳書向け集計
- CSV出力
- 総勘定元帳・試算表・貸借対照表
- 複数事業・複数口座への対応

## 5. 非機能要件
- 金額は円単位の整数で保存し、小数を使用しない
- 日付は日本時間で扱う。日付のみの会計項目はPostgreSQL `DATE` を使用する
- 会計データはユーザー間で分離する
- 仕訳は借方・貸方が一致する
- 取引の編集・取消履歴を追跡できる設計にする
- APIキー等の秘密情報をアプリへ埋め込まない
- 画面ロジックとスタイルを別ファイルに分離する

## 6. MVP完成条件
- 収入・支出を登録できる
- 取引に対応する仕訳を作成できる
- 仕訳の借方合計と貸方合計が一致する
- 未入金・未払を管理できる
- 月別・年別の収支を集計できる
- 別ユーザーのデータへアクセスできない
- iPhone実機で主要操作を確認できる

## 7. MVP対象外
- 税務申告書の電子提出
- 税額の最終確定・税務判断の自動化
- 銀行API・カードAPIとの自動同期
- OCRによる自動登録
- 外貨・複数通貨
