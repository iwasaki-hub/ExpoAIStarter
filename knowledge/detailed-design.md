# 詳細設計書 v1.0

## 1. 基本方針
画面上は収入・支出を簡単に入力できるようにし、内部では取引データから複式簿記の仕訳を生成する。青色申告・白色申告で元データを分けず、共通の取引・仕訳データから帳簿や集計を作る。

## 2. 基本仕様
| 項目 | 仕様 |
|---|---|
| 対象 | 日本の個人事業主 |
| 通貨 | JPYのみ |
| 金額 | 円単位の整数 |
| 会計期間 | 1月1日〜12月31日 |
| タイムゾーン | Asia/Tokyo |
| 申告方式 | blue / white |
| 入力方式 | 簡単入力 |
| 内部方式 | 複式簿記 |
| クライアント | Expo / React Native / TypeScript |
| DB | Supabase / PostgreSQL |

## 6. 取引処理
- 取引の発生日と入金日・支払日を区別する。
- 未入金売上は売掛金を使用する。
- 未払経費は未払金・買掛金等を使用する。
- 入金・支払は別の決済イベントとして記録できる設計にする。
- 一部入金・一部支払を許容する。
- 取引の訂正は、確定済み仕訳を直接破壊せず、取消・再計上等の監査可能な方法を採用する。

## 7. 自動仕訳例
### 現金売上
借方：現金 100,000円 / 貸方：売上高 100,000円

### 未入金売上
借方：売掛金 100,000円 / 貸方：売上高 100,000円

### 売掛金の入金
借方：普通預金 100,000円 / 貸方：売掛金 100,000円

### 現金経費
借方：通信費 5,500円 / 貸方：現金 5,500円

### クレジットカード利用
借方：通信費 5,500円 / 貸方：未払金 5,500円

### カード代金引落し
借方：未払金 5,500円 / 貸方：普通預金 5,500円

### 事業主貸
借方：事業主貸 / 貸方：普通預金

### 事業主借
借方：経費等 / 貸方：事業主借

※消費税の税込・税抜処理、端数処理、課税区分ごとの仕訳は、事業者設定と対象取引に応じて別途詳細化する。

## 8. 勘定科目
初期候補：
- 資産：現金、普通預金、売掛金、備品
- 負債：買掛金、未払金、借入金
- 収益：売上高、雑収入
- 費用：仕入高、通信費、消耗品費、旅費交通費、地代家賃、水道光熱費、広告宣伝費、支払手数料、接待交際費、租税公課、減価償却費
- 事業主勘定：事業主貸、事業主借

勘定科目は事業者単位で保持し、初期テンプレートから作成する。ユーザーによる追加・無効化を許容する。

## 9. 集計
- 月別収入：対象月に発生した収益仕訳の金額
- 月別経費：対象月に発生した費用仕訳の金額
- 収支差額：収入合計 − 経費合計
- 年別集計：1月1日〜12月31日
- 入金額・支払額と発生ベースの収益・費用を混同しない。ホーム画面では表示指標の定義を明示する。

## 10. 消費税・申告方式
- 消費税の免税・課税区分、インボイス登録状況、税込・税抜経理方式等を事業者設定として保持する。
- 税率・経過措置をソースコードへ固定値として埋め込まない。
- 将来の複数税率混在に備え、取引明細単位の税区分へ拡張できるようにする。
- 青色申告・白色申告は共通の取引・仕訳データから帳簿・帳票を生成する。
- 申告書の自動作成・税務判断はMVP対象外。対象年の法令・公的資料に基づく別途検証を必須とする。

## 11. バリデーション
- 金額は1円以上の整数
- 日付は有効な日付
- 取引種別に合った勘定科目を選択
- 決済状態と決済情報の整合性を確認
- 事業者所有権をサーバー側で確認
- 二重送信を防ぐ冪等キーを使用
- 仕訳確定時に借方合計＝貸方合計を検証
- 締め済み期間の変更は制限する

## 12. 監査・訂正
- 仕訳確定後の明細を無断で上書きしない。
- 訂正時は取消仕訳と再仕訳を作成する方式を基本とする。
- 作成者・作成日時・更新日時・取消理由を追跡できるようにする。
