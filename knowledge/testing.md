# テスト方針

## 1. 開発時の基本チェック
```powershell
npx expo-doctor
npx tsc --noEmit
npx expo lint
```

## 2. 会計ロジックの単体テスト
- 現金売上の仕訳
- 未入金売上の仕訳
- 売掛金入金の仕訳
- 現金経費の仕訳
- カード経費の仕訳
- カード引落しの仕訳
- 事業主貸・事業主借
- 借方合計＝貸方合計
- 0円・負数・上限超過の拒否
- 円単位整数の維持

## 3. DB・RLSテスト
- ユーザーAはユーザーAの事業データを読める
- ユーザーAはユーザーBの事業データを読めない
- ユーザーAはユーザーBのデータを更新・削除できない
- 子テーブルからの越境アクセスができない
- 未認証ユーザーが保護データへアクセスできない

## 4. iPhone実機テスト
- 収入登録
- 支出登録
- 入力エラー表示
- 取引一覧
- 取引詳細
- 月別集計
- ログアウト・再ログイン後のデータ保持

## 5. 受け入れ条件
機能ごとに、実装前に期待結果を定義し、実機・DBの両方で確認する。テスト結果はGitHubの変更と一緒に記録する。
